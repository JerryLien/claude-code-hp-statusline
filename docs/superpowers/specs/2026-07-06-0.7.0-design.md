# 0.7.0 Design — subagentStatusLine, downgrade guard, kind/repo badges, contract notes

Date: 2026-07-06. Approved by Jerry after brainstorming. All Claude Code payload
facts below were verified against the v2.1.201 binary (reverse-engineered
payload builder + settings schema), not docs alone.

## Scope

1. **subagentStatusLine renderer** — themed per-subagent rows (main feature)
2. **`/statusline-update` downgrade guard** — three-way version compare before install
3. **`pr.kind` + `workspace.repo` badges** — small display upgrades
4. **README field-compatibility notes** — document undocumented-but-emitted fields

## §1 subagentStatusLine

**Contract (verified, 2.1.201):** setting `{"subagentStatusLine": {"type":"command","command":...}}`.
stdin JSON: `session_id`, `transcript_path`, `cwd`, `prompt_id?`, `agent_type?`,
`columns` (usable width), `tasks[]` with `id`, `name?`, `type`, `status`,
`description`, `label` (may equal description), `startTime` (epoch ms),
`tokenCount` (number), `tokenSamples` (number[], ≤16 totals sampled ~5s),
`cwd`. stdout: one `{"id","content"}` JSON object per line. Partial output OK
(missing ids → default row). Non-zero exit → all default. Command timeout 5s,
re-run every 5s (first run 300ms). Rendering is single-row, ANSI + OSC 8
supported, truncated by Claude Code (ANSI-aware).

**Architecture:** same script, auto-detect. `statusline-hp.sh` string-probes
stdin for `"tasks"` (cheap gate), then a Python step confirms
`isinstance(d.get("tasks"), list)`; if confirmed it renders and prints the JSON
lines itself and the script exits 0. Otherwise fall through to the existing
main-statusline flow. Both settings entries point at the same file.

**Row format:** `<status glyph> <name> <trend> <tokens> <elapsed>`

| element | rpg | bloom | rule |
|---|---|---|---|
| status glyph | ⚔ running / 💀 completed / ☠ failed·killed / ⏳ queued·waiting | 🌱 / 🌸 / 🥀 / 💤 | unknown status → running glyph (wildcard) |
| name | bold; fallback chain `name → label → description → type` | same | bundle confirms `name` optional |
| trend | last 8 deltas of `tokenSamples`, normalized to `▁▂▃▄▅▆▇█`, cyan | last 4 deltas → `🌱🌿🌸🌼` 4-level | <2 samples → omit |
| tokens | `tokenCount` compact (`12.3k`) | same | 0 → `0` |
| elapsed | dim `♔1m24s` from `now - startTime/1000` | dim `⏱1m24s` | missing/invalid startTime → omit |

JSON emitted with `json.dumps` per line. Per-task render errors: skip that line
(Claude Code falls back to the default row for it) — natural degradation.
Theme resolution identical to main flow (env `STATUSLINE_THEME` >
settings.json `env.STATUSLINE_THEME` > rpg).

## §2 `/statusline-update` downgrade guard

Rewrite the bash snippet in `commands/statusline-update.md` (and the installed
skill copy):

1. Fetch remote `VERSION` to a temp file.
2. Read installed `STATUSLINE_HP_VERSION` from `~/.claude/statusline-hp.sh`.
3. Compare with `sort -V`: **remote ≤ installed → abort with an explanation**
   (mention local-ahead-of-GitHub as the likely cause; no overwrite). Only
   remote > installed proceeds.
4. Download to a temp path, validate (`bash -n` + embedded version equals the
   fetched VERSION), then move into place and refresh the cache.

Rationale: on 2026-07-06 the unconditional download downgraded an installed
0.6.0 to GitHub's then-stale 0.5.0.

## §3 pr.kind + workspace.repo badges

- `pr.kind == "cr"` (remote code-review session; undocumented field, verified
  emitted): PR badge icon becomes `🔍` in both themes (`🔍#123✓`). Any other
  kind or absence → existing themed icons (`🔀`/`🌷`).
- `workspace.repo.owner` **and** `.name` both present → directory badge shows
  `📁 owner/name` instead of `📁 <dir basename>`. Either missing → unchanged.

## §4 README field-compatibility notes

New README section listing fields the script consumes that are **emitted but
not in the official statusline schema** — `fast_mode`, `pr.kind` — with the
verified version (2.1.201) and the caveat that they may change without notice.

## Tests

- Subagent mode: valid JSON-lines output; per-theme glyphs; sparkline
  presence/absence (<2 samples); name fallback chain; elapsed omission;
  non-tasks payload with a literal `"tasks"` substring in another field does
  NOT trigger subagent mode; main flow unaffected.
- Downgrade guard: run the extracted snippet against a mock HOME + PATH-shimmed
  `curl` serving controlled VERSION/script bytes; assert abort on equal/older,
  install on newer.
- pr.kind: `cr` swaps icon (both themes); other/absent kinds keep theme icon.
- repo badge: owner+name shows `owner/name`; partial repo object falls back.
